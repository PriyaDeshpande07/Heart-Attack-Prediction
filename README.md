# ❤️ Heart Attack Prediction using Machine Learning

## 📌 Project Overview

This project predicts the likelihood of heart disease using machine learning algorithms based on clinical parameters such as age, blood pressure, cholesterol, chest pain type, maximum heart rate, and other medical features.

The project includes:
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Machine Learning model training
- Model comparison
- Performance evaluation

---

## 📂 Dataset

- Dataset: Heart Disease Dataset
- Total Records: 1025
- Features: 13
- Target Variable: Heart Disease (0 = No Disease, 1 = Disease)

---

## 🤖 Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Gaussian Naive Bayes

---

## 📈 Model Performance

The Decision Tree and Random Forest models achieved the highest accuracy on the test dataset.
